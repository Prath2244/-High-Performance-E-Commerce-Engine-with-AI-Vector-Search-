High-Performance E-Commerce Engine with AI Vector Search is a MERN-stack project that combines Redis caching and MongoDB vector search to deliver ultra-fast product search and page loads for large e-commerce catalogs. It implements the Cache-Aside Pattern to reduce database load and improve performance during high-traffic sales events. The project also includes a React 19 admin dashboard and a GitHub Actions CI/CD pipeline for secure catalog management and automated quality checks.
